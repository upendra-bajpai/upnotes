System Flow Diagram

The system uses a decoupled, event-driven architecture. A lightweight web service ingests webhook events and writes them to Firestore, which then triggers a scalable Cloud Function to perform the heavy lifting of the AI review process.

1. GitHub Webhook Trigger
2. FastAPI on Cloud Run (Ingestion & Verification)
3. Create Task in Firestore Collection
4. Cloud Function Worker (Triggered `onCreate`)
5. LangGraph Agent Orchestration
6. Post Comment to GitHub PR

Framework Comparison

LangChain with LangGraph is recommended over LangFlow for its production-grade capabilities, superior control over complex agent interactions, and robust observability through LangSmith.

Technology & Deployment

The system is built on a modern, serverless stack designed for scalability and maintainability from day one.

Core Technology Stack

  • 📦
    Containerization (Ingestion): Docker & Gunicorn for the FastAPI webhook receiver.
  • ⚙️
    Serverless Worker: Google Cloud Functions for event-driven, scalable AI processing.
  • ☁️
    Task Queue Database: Google Firestore to reliably queue review tasks.
  • 🧠
    Vector Store (RAG): A dedicated managed vector DB (e.g., Pinecone, Astra DB) for context storage.
  • 🚀
    CI/CD: GitHub Actions to automate testing, building, and deploying all components.
